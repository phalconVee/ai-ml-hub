# Kestrel Greenhouse: Growing Notes

The greenhouse grows lettuce, radish, kale and dwarf tomatoes in hydroponic trays. Seedlings stay in
the propagation rack for 12 days before moving to the main trays.

Nutrient solution is mixed to an electrical conductivity of 1.6 to 2.0 mS/cm for leafy greens and 2.5
for tomatoes. The pH is kept between 5.8 and 6.2; check it every morning with the handheld meter and
correct with the pH-down solution, never with vinegar.

Tomatoes need hand pollination at this altitude because there are no insects: tap each flower truss
with an electric toothbrush around midday, when the pollen is driest.

Aphids appeared twice last season. The fix that worked was releasing ladybird larvae from the supplier
in Varn, not spraying, because spray residue damaged the radish crop.
